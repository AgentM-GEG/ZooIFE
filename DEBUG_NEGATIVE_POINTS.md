# Debug Negative SAM Points Implementation

## Overview
Enhanced the SAM2 integration to help diagnose why negative (background) points have weak effect on segmentation masks by displaying all candidate masks and their selection rationale.

## Problem Statement
User observed that:
- Right-clicking to add negative/background points has very weak effect on segmentation
- Positive points seem much more influential
- Unclear whether this is:
  - SAM model design limitation
  - Mask selection algorithm issue
  - Coordinate/placement problem

## Solution Architecture

### Backend Enhancement (server/sam2_server.py)
**Changes:**
1. Always return mask selection info even when debug=False
2. In debug mode, return all 3 candidate masks generated by SAM

**Response Structure:**
```python
{
  "image": { "url": "data:image/..." },
  "mask_selection": {
    "selected_idx": 0,           # Which mask was selected (0-2)
    "selected_iou": 0.891,       # IoU score of selected mask
    "all_iou_scores": [0.891, 0.812, 0.705],  # All 3 IoU scores
    "has_background_prompts": true
  },
  "debug_url": "data:image/...",  # Original image with point markers
  "debug_masks": [                 # All 3 candidate masks
    {
      "idx": 0,
      "iou": 0.891,
      "url": "data:image/...",
      "is_selected": true
    },
    ...
  ]
}
```

**Point Visualization:**
- Green circles: Foreground/positive points (label=1)
- Red circles: Background/negative points (label=0)
- White crosshairs: Point location markers

### Frontend Store (src/stores/classificationStore.ts)
**New State Fields:**
```typescript
debugMasks: Array<{
  idx: number;
  iou: number;
  url: string;
  is_selected: boolean;
}> | null;

maskSelectionInfo: {
  selected_idx: number;
  selected_iou: number;
  all_iou_scores: number[];
  has_background_prompts: boolean;
} | null;
```

**New Action:**
```typescript
setDebugMasks: (masks, selectionInfo) => void
```

### Frontend UI (src/components/ImageCanvas/DebugMasksPanel.tsx)
**New Component Features:**
- Grid layout showing all 3 candidate masks side-by-side
- IoU score for each mask prominently displayed
- Visual highlight of selected mask
- Selection info panel explaining:
  - Which mask was selected and why
  - All IoU scores in comparison
  - Note if background prompts were used

## Usage Workflow

1. **Enable Debug Mode**: Check debug coordinates option in UI
2. **Add Points**: Click to add foreground, right-click to add background points
3. **View Results**:
   - Point markers shown on original image (green/red by type)
   - All 3 candidate masks displayed with IoU scores
   - Selected mask highlighted

4. **Diagnose**:
   - **All masks very similar**: Background points being ignored by model
   - **Different masks, selected one poor**: Bad mask selection algorithm
   - **Points wrong location**: Coordinate transform issue
   - **Other mask better respects background**: Can try adjusting selection logic

## Technical Details

### Mask Generator Behavior
SAM returns 3 masks automatically:
- Mask 0: Best quality (uses `multimask_output=True`)
- Mask 1: Alternative quality
- Mask 2: Alternative quality

Each has an IoU prediction score. Current logic picks `argmax(iou_scores)`.

### Why Negative Points Weak
**Likely causes:**
1. **Model design**: SAM trained primarily on positive prompts
2. **IoU unreliability**: IoU predictions unreliable with background points
3. **Iterative refinement missing**: SAM2 supports multi-round refinement via embedding cache (not implemented)

### Future Improvements
Could implement:
- SAM2 interactive mode with embedding cache
- Custom mask selection heuristic for background-heavy prompts
- Multi-round refinement for better negative point support
- Weighting mechanism for positive vs negative point influence

## Related Issues & Solutions

**Issue:** Negative points have minimal effect
**Investigation Path:**
1. Check if all 3 masks are identical (model limitation)
2. Check if other masks look better (selection algorithm issue)  
3. Check if points are in correct location (coordinate issue)
4. Consider SAM2 iterative refinement if available
