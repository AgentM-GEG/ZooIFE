# Development History Archive

This folder contains historical implementation notes and bug-fix writeups.

These files are useful for understanding how issues were debugged and resolved over time, but they are not guaranteed to match current production behavior.

For canonical, current documentation, use:

- `docs/MASK_HISTORY_SYSTEM.md`
- `docs/STORES.md`
- `docs/SOLUTION_ARCHITECTURE.md`

## Archived Files

- `MASK_BUG_FIX.md` — Historical note about mask type/composite accumulation fixes.
- `MASK_MIXING_BUG_FIX.md` — Historical note about compositing consistency and SAM mixing fixes.
- `REFACTORING_SUMMARY.md` — Historical summary of services and hooks refactoring phases.
